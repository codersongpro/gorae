# 고래곳간 (Gorae Gotgan)

> 사람과 수업은 웨일이 연결하고, 고래곳간은 교육 자료와 도구를 이어 준다.

고래곳간은 교사와 학생이 만든 학습자료·수업도구·발표자료·업무도구를 모아 필요할 때 찾아 쓰고, 웨일 클래스와 팀보드에서 공유하며, 다시 수정하고 발전시키는 교육용 디지털 곳간입니다. NWEC 2026 웨일 스페이스 수업도구 공모전 출품작.

교과 학습·자기주도학습·발표·수업 운영·학급 운영·교사 행정업무·수업자료 관리와 교사 공동체를 지원합니다. AI와 바이브코딩은 필요한 자료와 도구를 직접 만드는 여러 제작 방법 중 하나입니다.

자료별 활용 수준과 일반 교과·자기주도학습·발표·교사 업무·학급운영·직접 제작의 여섯 가지 시연 흐름은 [교육자료 활용 안내](docs/education-materials.md)에 정리했습니다.

```
찾기 → 활용 → 수업·학습·발표에 공유 → 필요에 따라 피드백·수정 → 다시 활용
```

## 지금 되는 것 (2026-10-03 기준, 실제 코드와 시험으로 확인)

- **세 곳간**
  - **인증 곳간**: 파수꾼고래가 검수 서명한 작품. 배지(맑은 바다·얕은 바다·소용돌이)는 서명 검증을 통과할 때만 보입니다.
  - **나눔 곳간**: 누구나 구글 폼으로 올린 **검수 전** 작품. 모든 카드에 '검수 전'·'얕은 바다' 표시, 학생고래는 미리 보기만(자동 점검에 걸리면 미리 보기도 교사 확인 필요), 담기는 교사고래만.
  - **내 곳간**: 기기 안(IndexedDB)에만 저장. 만들기·수정·리믹스·꾸러미·공유.
- **분류**: 수업/업무 → 대표 카테고리 → 하위 카테고리 → 태그, 교과활동은 학교급·학년·교과·영역·단원·차시·주제·성취기준·예상 시간·활동 형태. 검색·자세한 조건.
- **작품 형태**: HTML(격리 실행) · 웹앱·자료 링크·파일 링크(https 주소, 확인 후 새 창) · EXE(교사고래 전용, 아래 참고).
- **격리 실행**: HTML은 별도 창의 sandbox 페이지 → `allow-same-origin` 없는 iframe, CSP로 fetch·XHR 등 외부 요청 차단.
- **자동 안전 점검**: 외부 전송·개인정보 입력칸·API 키·외부 스크립트·위험 동작 경고 (정규식 기반 경고이며 보안 경계는 아님).
- **검수 서명(꼬리지문)**: ECDSA P-256 3단계 검증(고래 족보 관리 서명 → 파수꾼고래 등록·미말소 → 작품 내용 해시). 서명 뒤 내용이 바뀌면 배지를 지우고 "서명 뒤 내용이 바뀌었습니다."를 보여 줍니다.
- **고래 족보·이달의 고래자리·고래 픽·고래 노래**: 모두 서명 확인 후에만 표시. 고래 노래는 교사고래가 의견 설문으로 보내고 파수꾼고래가 골라 서명합니다.
- **꾸러미(.gorae.json)** 내보내기·가져오기(고른 작품만), **리믹스·버전 계보**(원작 검수 서명은 따라가지 않음).
- **바로 실행 링크와 웹 뷰어**(`site/viewer.html`, 모바일 지원)
  - 인증 곳간 작품: 짧은 링크 `viewer.html?id=작품id` → 뷰어가 catalog.json에서 찾아 서명을 다시 확인
  - 그 밖의 작품: 작품을 압축해 `#g1.…` 뒤에 담는 링크(서버로 전송되지 않음)
  - 압축해도 너무 크면 꾸러미 파일 안내
- **웨일 서비스 공유**(붙여넣기 방식, 공식 API 연동 아님): 웨일 클래스 안내문 · 팀보드 전시 카드 · 웨일온 공유 글을 복사하고 작품 파일을 저장한 뒤 그 서비스를 엽니다. **모든 공유 글에 검수 상태가 들어가고**, 미검수 작품은 "아직 검수되지 않은 작품입니다", 소용돌이(보류) 작품은 공유하지 않습니다. 사이드바는 메인 탭 도메인(클래스·팀보드·웨일온)을 기기 안에서만 보고 버튼 순서를 바꿉니다.
- **UBT 평가용 정보 복사**: 자료명·교과·성취기준·결과물 링크·버전·설명(원작·프롬프트 레시피는 있을 때만)를 붙여넣기용 글로 복사합니다. UBT 자동 제출·자동 채점·시험 화면 잠금은 **하지 않습니다**.
- **교사고래 / 학생고래**: 교사고래 전환은 기기별 PIN(4~8자리, PBKDF2 해시 저장, 5회 틀리면 30초 잠금). **기본 PIN은 없습니다** — 처음 전환할 때 직접 정합니다. PIN은 학생 앞 실수 방지용이고 진짜 신뢰 경계는 검수 서명입니다.
- **물뿜기**: 좋아요처럼 누르면 숫자 반영(로그인 없는 구글 설문에 작품 id·교사/학생 구분만 자동 제출 → 응답 시트를 읽어 집계), 다시 누르면 취소. 숫자는 부풀릴 수 있어 정렬·전시 기준은 서명된 고래 픽입니다.
- **수업 진행**: 내 곳간에서 고른 작품을 도입 → 활동 → 정리 순서로 엽니다.
- **검수 도구**(`site/review.html`): 검수 목록·검수대(자동 점검·코드 보기·격리 실행 → 검수 서명) · 고래 족보 관리 · 이달의 고래자리 · 물뿜기 집계. 로그인은 파수꾼고래 본인의 검수 열쇠 백업 파일 + 암호.
- **웹 버전**(`site/app/`): 사이드바 코드를 그대로 복사해 브라우저에서도 씁니다(탭 주소 보기·구글 드라이브 직접 받기는 빠짐).

### EXE에 대해
고래곳간은 교육적 자료 유형과 실행 형식을 구분합니다. 현재 HTML 격리 실행과 자료·웹앱·파일의 HTTPS 링크를 지원합니다. EXE는 보조 기능으로만 둡니다: 교사고래만 등록, 학생고래에서는 보이지 않음, 파일은 보관하지 않고 다운로드 링크 + SHA-256 + 소스 저장소 + 검사 결과 + 실행 환경만 기록, 검수 서명이 확인된 항목만 다운로드 링크 표시, 강한 외부 프로그램 경고. 인증 곳간 EXE 목록(`exeItems`)은 사이드바 목록에 노출하지 않습니다.

## 아직 안 되는 것 (구현됐다고 쓰지 않음)
- UBT 자동 연동(제출·채점·시험 잠금), 웨일 스페이스 공식 API 연동
- QR 코드 만들기
- 나눔 곳간 업로드 파일의 목록 단계 자동 점검(파일 내용 점검은 미리 보기·가져오기 때 함), 공개목록 CSV의 운영 설정( `docs/google-form.md`)
- 앱 안 댓글·평가·명단(만들지 않음 — 웨일 서비스가 맡음)

## 개인정보
고래곳간은 사용자 식별정보(이름·이메일·학교명·전화번호)를 직접 수집·저장하지 않습니다. 작성자 표시는 **닉네임 · 학교급**만 씁니다.
구글 폼(나눔 곳간 제출·물뿜기·고래 노래)과 GitHub Pages 같은 외부 서비스에는 그 서비스의 일반적인 접속 기록이 남을 수 있고, 파일을 올릴 때는 구글 계정 로그인이 필요합니다. 자세한 흐름은 `docs/google-form.md`.

## 개발·시험
```
npm run sync   # 공용 파일을 extension/·site/로 복사
npm test       # sync + 단위 시험 전체
```
- 운영 열쇠(관리 열쇠·검수 열쇠) 준비·백업·교체: `docs/root-key-setup.md` (`tools/keys.mjs`)
- 샘플 목록 다시 서명: `node tools/build-sample.mjs` (저장소 밖 열쇠 폴더 필요)
- 변조 시연용 꾸러미: `node tools/make-tamper-demo.mjs` → `output/demo/`

## 폴더
- `extension/` 웨일 사이드바 확장앱 · `site/` GitHub Pages(인증 곳간 목록·족보·뷰어·검수 도구·웹 버전)
- `shared/` 확장앱·뷰어·검수 도구 공용 코드 · `design/tokens.css` 디자인 토큰
- `samples/` 수업·업무 활용 예시 · `tools/` 동기화·서명·열쇠 도구 · `tests/` 단위 시험
- `docs/google-form.md` 나눔 곳간 운영 설정 · `docs/root-key-setup.md` 운영 열쇠 관리
