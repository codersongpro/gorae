# 고래곳간 디자인 결과물 (원티드 디자인 시스템 기반)

이 폴더를 그대로 `gorae/design/import/`에 덮어 넣고, HANDOFF.md의 '디자인 합류' 지시문을 Claude Code에 주면 됩니다.

## 들어 있는 것
- `tokens.import.css` — design/tokens.css와 **같은 변수 이름**, 값만 교체(라이트·다크). 맨 아래 추가 제안 변수 5개.
- `components.md` — 공통 컴포넌트 치수·색·상태, 줄바꿈 규칙.
- `screens/고래곳간 사이드패널.html` — 오프라인으로 열리는 인터랙티브 시안. 왼쪽 "화면 바로가기"로 13개 상태 이동.

## 시안 성격
고해상도(hifi) 시안입니다. HTML은 **참고용**이고 그대로 붙이는 코드가 아닙니다. extension/ui/(views.js, app.css)를 tokens.css 변수만 써서 다시 그려 주세요. 문구는 strings.js 기준을 유지하되 아래 '문구 변경'만 반영.

## 화면 목록 (사이드패널 360px)
1. 인증 곳간 — 이달의 고래자리 → 검색 → 필터 칩 → 개수·정렬 → 카드 목록
2. 나눔 곳간 — 미검수 안내 띠 → 종류 칩 → 카드([미리 보기] [가져오기])
3. 내 곳간 — 저장 안내 → 체크박스 카드([실행·수정·리믹스·삭제] 4등분)
4. 학급 꾸러미(교사) — 3단계 표시 → 작품 고르기 → 이름·한마디 → 만들기 → 복사·저장 목록. 학생 모드면 잠금 안내.
5. 작품 상세 — 배지 → 제목·설명·메타 → 검수 서명 상자(확인/불일치/없음) → 사용 방법 → 프롬프트 레시피[복사] → 버전 → 고래 노래 → 웨일 공유 → 하단 고정 [🐳 물뿜기] [실행]
6. 실행 뷰 — 52px 도구줄([닫기] 제목+"격리 실행 중" [새 탭] [링크] [🐳]) + iframe
7. 만들기 — 3분할 선택(HTML/파일/주소) → 제목 → 입력 → [자동 점검] 후 결과 목록 → [내 곳간에 저장] 활성
8. 가져오기 — 파일 놓기/붙여넣기 → [확인하기] → 작품별 서명 상태 체크 목록 → [선택한 작품 담기 (n개)]
9. 교사고래 암호, 10. 시험 잠금, 11. 빈 상태

## 이모지 사용 (원티드 기본 규칙의 예외로 이 앱만 허용)
- 🐋 앱 헤더 로고 자리(24px). 기존 icon128.png 대신.
- 🐳 물뿜기 표시 전부(카드 18px, 상세·실행 뷰 20px).
- 그 외 고래 용어(고래 픽, 고래 노래 등)는 원티드 아이콘 사용. 💨🎵는 쓰지 않음.

## 문구 변경
- 어미고래 → 교사고래 모드 (tokens.css 주석의 "어미고래 모드 띠" 포함)
- 물뿜기 버튼 눌림 상태: "뿜었어요"

## 상태
mode(student|teacher), tab, screen(null|detail|run|create|import|pin), liked{id}, added{id}, 선택 집합(mypod, import, class), 필터(query, pickOnly, badge, sort), toast. 시험 잠금은 mode보다 우선.

## 확인 필요
- `--color-mypod` #00788C는 원티드 cyan-40(#0098B2)보다 진하게 잡았습니다(탭 글자 대비 때문). 시안 화면은 cyan-40이라 약간 다릅니다.
- 배지 글자도 대비 때문에 -30 단계를 썼습니다. 시안의 -40보다 진합니다.
- 검수 도구(PC)와 바로 실행 뷰어(반응형)는 아직 시안이 없습니다.
