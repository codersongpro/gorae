# 교육자료·도구 활용 안내

고래곳간은 자료를 찾고 활용한 뒤 웨일 클래스·팀보드·웨일온으로 연결하는 교육용 디지털 곳간이다. AI와 바이브코딩은 필요한 자료가 없을 때 선택하는 제작 방법이다.

자료의 교육적 용도(contentType)와 실행 형태(artifactType)는 별도로 저장한다. PDF·슬라이드·이미지는 현재 HTTPS 파일 링크로 등록한다. 파일 업로드 저장소나 발표 편집기를 제공하는 것은 아니다.

## 예시 자료의 활용 수준

인증 곳간 38개, 나눔 예시 8개, 내 곳간 예시 3개 카드에 자료별 목표·준비·활동·확인 질문·정리 안내가 포함되어 있다. 서명은 내용의 무결성과 검수 상태를 확인하며 실제 학급에서의 효과를 보증하지 않는다. 학생 수준과 교과서에 맞는 최종 조정은 교사가 맡는다.

| 자료 | 활동과 확인 | 결과 보관 |
| --- | --- | --- |
| 분수 피자 / 혼자 공부하는 분수 비교 | 같은 크기 피자 조작, 분모·분자 비교, 6문제 해설, 오답 재도전 | 비교 방법과 예를 공책·외부 문서에 정리 |
| 구구단 번개 퀴즈 | 단 선택, 10문제, 반복 덧셈 해설, 오답 재도전 | 오답과 다시 연습할 단 기록 |
| 곱셈 연습 카드 | 세 자리×두 자리 8문제, 부분곱 설명, 답 확인 후 진행 | 계산 과정과 실수 원인 정리 |
| 물의 상태 시뮬레이션 | 1기압 순수한 물의 이상화 모형, 예측·관찰 기록, 경계 온도에서 상태 공존 설명 | 관찰표와 근거 정리 |
| 주장과 근거 찾기 | 4개 판단 문제와 해설, 주장·근거·출처·반론 작성 | 작성 내용을 외부 학습 문서에 보관 |
| 우리 지역 인구 조사 발표 | 표·그래프, 변화량 계산, 발견한 점·출처·추가 질문, 발표 화면과 수정 | 복사 가능한 발표 요약 보관 |
| 설문 CSV 집계기 | 따옴표·쉼표·줄바꿈 처리, 열 선택, 빈칸·빈도·비율 확인 | 집계 결과를 외부 업무 문서에 보관 |
| 공문 할 일 추출기 | 업무 후보와 원문 행, 누락 추가·제외, 기한·담당 수정, 원문 대조와 완료 표시 | 검토 상태가 포함된 목록 보관 |

국어 판단 문제와 인구 기본 수치는 직접 작성한 가상 예시다. 실제 연구나 지역 통계로 인용하지 않는다. 입력과 학습 결과는 실행 화면에서만 유지되며 자료 공유 링크에는 입력한 학습 결과가 자동 포함되지 않는다. 발표·제출 전에 결과를 별도 문서로 보관한다. 구구단·곱셈 원본은 기존 미검수 상태를 유지한다.

## 여섯 가지 시연 흐름

1. 일반 교과: 인증 곳간에서 `초4 수학 분수 10분`을 검색하고 엔터를 누른다. 분수 자료를 실행한 뒤 ⋯ → 클래스 활용 방식 → 수업에 활용을 선택한다. 복사된 글과 꾸러미 파일을 클래스에서 직접 게시한다.
2. 자기주도학습: 무엇을 찾으세요? → 혼자 공부하기에서 분수 비교를 연다. 개념 2분 → 조작 3분 → 확인 3분 → 정리 2분으로 진행하고 오답을 다시 풀며 결과를 기록한다.
3. 발표·공유: 발표·공유에서 인구 조사 발표를 연다. 가상 자료로 먼저 연습하고 실제 자료를 쓰면 출처를 작성한다. 발표 요약을 보관하고 팀보드 발표 공유 또는 피드백 템플릿과 함께 게시한다. 친구의 새로 알게 된 점·궁금한 점을 받아 발표를 수정한다.
4. 교사 업무: 교사고래 모드에서 교사 업무 → 교무·행정으로 찾는다. 공문 예시를 내 곳간에 담고 익명화한 본문으로 후보를 추출한다. 원문과 기한·담당을 대조한 뒤 목록을 보관한다. 내 곳간의 교사 업무·최근 사용 보기로 반복 활용한다.
5. 학급운영: 학급운영 → 모둠편성 또는 자리배치를 고른다. 학생 이름 대신 번호·기호를 쓰고 누락·중복을 확인한다. 결과는 교사가 조정하고 교실 운영에 적용한다.
6. 직접 제작: 필요한 자료가 없으면 만들기에서 교육 목적·자료 유형·실행 형태를 정한다. 제작 방법은 선택 사항이다. 자동 안전 점검과 교사 확인을 거쳐 내 곳간에 저장하고 공유한다. 수정·리믹스 후에는 검수를 다시 받는다.

웨일온에서는 오늘 사용할 자료·발표자료·학습자료·짧은 수업도구를 꺼내며 네 개를 고르면 도입 → 활동 → 발표 → 정리 순서로 진행한다. 공유와 UBT 평가용 정보는 붙여넣기용 글과 파일을 만드는 방식이며 공식 API 자동 게시·제출·채점을 수행하지 않는다.

운영 나눔 곳간은 별도 공개목록 CSV를 연결해야 한다. 원응답 시트의 공개 범위 변경과 공개목록 생성은 운영자가 외부 Google 서비스에서 수행해야 한다. 설정이 비었거나 공개목록 읽기가 실패해도 원응답을 읽지 않는다.
