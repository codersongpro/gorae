# 구글 설문 설정 안내 (큰 곳간 작품 공유)

네이버 폼은 파일 업로드 형식이 제한적이라(HTML 불가) **구글 설문**으로 받습니다.
고래곳간 사이드바 작품 카드의 [자세히] → **큰 곳간에 공유하기**가 아래 문항 순서대로 답과 업로드 파일을 만들어 줍니다.
설문을 만든 뒤 응답 주소(https)를 `extension/core/config.js`의 `formUrl`에 넣어 주세요.

## 꼭 알아 둘 점
- **파일 업로드 문항이 있으면 응답자는 구글 로그인이 필요합니다.** (학교 구글 계정 사용)
  고래곳간 자체는 로그인이 없지만, 작품 제출 단계만 구글 계정을 씁니다.
- 올라온 파일은 **설문 만든 사람의 구글 드라이브**에 저장됩니다.
- 설문 설정에서 **이메일 주소 수집은 끕니다.** (파일 업로드 때문에 구글이 업로드한 사람을 기록할 수 있으니, 응답 시트를 공개하지 마세요.)

## 문항 (사용자 구성 그대로)
| # | 문항 | 형식 | 필수 | 이동 |
| --- | --- | --- | --- | --- |
| 1 | 어떤 고래이신가요? | 객관식: 학생고래 / 교사고래 | 예 | |
| 2 | 제작하신 분의 닉네임을 적어주세요. | 단답형 | 예 | |
| 3 | 제작한 앱의 제목을 적어주세요. | 단답형 (100자 이내) | 예 | |
| 4 | 제작한 앱이 html 또는 실행 파일인가요? | 객관식: 네 / 아니오 | 예 | 네 → 섹션 3, 아니오 → 섹션 2 |
| 5 | (섹션 2) 제작한 웹페이지 주소를 알려주세요. | **장문형** | 예 | 답변 후 → **설문 제출** |
| 6 | (섹션 3) 제작한 파일을 업로드 해주세요. | 파일 업로드 | 예 | |

- 4번의 "섹션으로 이동"은 객관식 문항 메뉴(⋮) → **답변을 기준으로 섹션 이동**에서 정합니다.
- **섹션 2 끝의 "다음 섹션"을 "설문지 제출"로 바꿔 주세요.** 그대로 두면 웹앱 제출자도 파일 업로드(필수)로 넘어가 제출하지 못합니다.
- 6번 파일 업로드: **특정 파일 형식만 허용 → 끄기**(HTML을 받으려면 꺼야 합니다), 최대 파일 수 1, 최대 크기 10MB.
- 5번은 단답형이 아니라 **장문형**이어야 합니다. 고래곳간이 주소 다음 줄에 작품 정보(분류·레시피)를 붙여 주기 때문입니다.

## 실행 파일(EXE)
고래곳간 규칙상 실행 파일 자체는 받지 않습니다. 앱은 EXE 작품을 **4번 "아니오" → 5번에 다운로드 링크·소스·SHA-256·검사 결과·실행 환경**으로 안내합니다.
(4번 문항 글을 "제작한 앱이 HTML 파일인가요?"로 바꾸면 덜 헷갈립니다.)

## 받은 뒤 (혹등고래 파수꾼)
1. 구글 드라이브의 설문 응답 폴더에서 올라온 `.html` 파일을 내려받거나, 응답 시트의 5번 칸 내용을 복사합니다.
2. 검수 도구 `https://codersongpro.github.io/gorae/review.html` → **2. 검수대**에서 파일을 고르거나 붙여 넣고 [확인하기]
   - 고래곳간에서 만든 파일은 맨 앞 주석에 작품 정보가 있어 분류·레시피가 그대로 살아납니다.
   - 고래곳간 밖에서 만든 HTML도 읽지만 분류 정보가 없다고 경고합니다.
3. 자동 점검·코드 보기·격리 실행으로 확인 → 배지·고래 픽 선택 → [검수 서명 찍기] → [catalog.json에 넣기] → 내려받기
4. 내려받은 `catalog.json`으로 저장소의 `site/catalog.json`을 바꿔 올리면 자동 배포 후 모두의 큰 곳간에 보입니다.

## 고래 노래·물뿜기 (의견 설문, 선택)
작품 설문에는 이 문항이 없으므로, 필요하면 **의견 설문**을 하나 더 만듭니다. 로그인 없이 받을 수 있습니다(파일 문항 없음).
- 문항 1개: 장문형 "고래곳간에서 복사한 내용"
- 주소를 `config.js`의 `feedbackFormUrl`에 넣으면 [고래 노래 보내기]·[물뿜기 보내기]가 이 설문을 엽니다.
- 받은 응답은 검수 도구 **4. 물뿜기 집계**(물뿜기)·**2. 검수대**(고래 노래를 작품에 붙여 다시 서명)에서 처리합니다.
