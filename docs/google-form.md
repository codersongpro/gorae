# 나눔 곳간 운영 설정 (구글 폼 → 구글 시트 → 구글 드라이브)

에듀노트 스킬마켓과 같은 구조입니다. 서버 없이 운영합니다.

```
[공유하는 사람] 작품 카드 → [자세히] → 나눔 곳간에 공유하기
  ① 업로드할 파일 저장(.html, 맨 앞 주석에 분류·레시피 정보)
  ② 미리 채워진 구글 폼 열기(고래·닉네임·제목·설명·분류·주소·한 마디 자동)
  ③ 폼에서 파일을 드라이브에 올리고 제출 → 응답 시트에 한 줄 추가
[가져오는 사람] 나눔 곳간 탭
  시트 CSV 불러오기 → 검색·분류 거르기 → [가져오기]
  → 드라이브 파일 받기 → 검증 → 내 곳간에 담기(출처: 나눔 곳간) → 실행 전 출처 확인
```

나눔 곳간 작품은 **미검수(얕은 바다)** 입니다. 검수 서명이 붙은 **큰 곳간**은 지금처럼 파수꾼이 검수 도구로 따로 올립니다.

## 운영자 체크리스트

### 1. 구글 폼 만들기 (문항 8개, 순서는 바뀌어도 됩니다)
| # | 질문 (이 낱말이 들어가야 시트 열을 찾습니다) | 형식 | 필수 |
| --- | --- | --- | --- |
| 1 | 어떤 고래이신가요? | 객관식: 학생고래 / 교사고래 | 예 |
| 2 | 제작하신 분의 **닉네임** | 단답형 | 예 |
| 3 | 제작한 앱의 **제목** | 단답형 | 예 |
| 4 | **설명** | 장문형 | 아니요 |
| 5 | **분류** (고치지 마세요) | 단답형 | 아니요 |
| 6 | 웹앱 **주소** (웹앱·실행 파일만) | 장문형 | 아니요 |
| 7 | **한 마디** | 단답형 | 아니요 |
| 8 | 제작한 **파일**을 업로드해 주세요 | 파일 업로드 | 아니요 |

- 8번 파일 업로드: **특정 파일 형식만 허용 → 끄기**(HTML을 받기 위해), 최대 파일 수 1, 최대 크기 10MB.
- 6번과 8번은 둘 중 하나만 채우므로 **필수로 하지 마세요.** 고래곳간이 HTML이면 파일, 웹앱·EXE면 주소를 안내합니다.
- 설정 → **이메일 주소 수집: 사용 안 함.** 파일 업로드 문항 때문에 응답자는 구글 로그인이 필요합니다(학교 계정).
- 폼 설명에 넣을 문장: "작품 안에 학생 이름·사진·연락처를 넣지 마세요. 닉네임만 써요."

### 2. 응답 시트 연결과 공유
1. 폼 **응답** 탭 → 스프레드시트에 연결
2. 시트 **공유 → 링크가 있는 모든 사용자 → 뷰어** (또는 파일 → 공유 → 웹에 게시 → CSV)
3. **파일 업로드 폴더**(드라이브의 폼 이름 폴더)도 **링크가 있는 모든 사용자 → 뷰어**로 공유
   - 안 하면 "시트나 파일이 공개되어 있지 않아요"가 뜨며 가져오기가 실패합니다.

### 3. 미리 채우기 entry 번호 확인
폼 오른쪽 위 ⋮ → **미리 채워진 링크 받기** → 1~7번 칸에 아무 값이나 넣고 **링크 받기** → 복사한 주소에서 `entry.숫자`를 질문별로 적습니다.

### 4. 고래곳간에 알려 줄 값 → `extension/core/market-config.js`
| 설정 | 어디서 |
| --- | --- |
| `sheetId` | 시트 주소의 `/d/` 와 `/edit` 사이 |
| `publishedCsvUrl` (선택) | 웹에 게시 → CSV 주소 |
| `formUrl` | 폼 **보내기 → 링크** (`https://docs.google.com/forms/d/e/.../viewform`) |
| `entry.whale` ~ `entry.comment` | 3번에서 적은 `entry.숫자` |

### 5. 관리
- 부적절한 등록: 시트에서 해당 **행을 삭제**하면 다음 새로고침부터 목록에서 사라집니다.
- 좋은 작품은 파수꾼이 드라이브에서 파일을 내려받아 검수 도구 **2. 검수대**에서 서명 → 큰 곳간에 올립니다.

## 보안
- 고래곳간은 시트·드라이브를 **https로, 쿠키 없이, 15초·2MB 상한**으로만 읽고, 리다이렉트 뒤 주소가 구글이 아니면 멈춥니다.
- 가져온 파일은 형식 검사(꾸러미 규칙·1MB)와 자동 점검을 거쳐야 저장되며, 실행은 격리된 창에서 외부 통신 없이 합니다.
- 나눔 곳간에서 가져온 작품은 처음 실행할 때 **출처 확인창**이 뜹니다.

## 고래 노래·물뿜기 (의견 설문, 선택)
로그인 없이 받는 장문형 1문항 설문을 따로 만들고 주소를 `config.js`의 `feedbackFormUrl`에 넣습니다. 응답은 검수 도구 **4. 물뿜기 집계**에서 처리합니다.
