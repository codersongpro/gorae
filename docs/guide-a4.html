고래곳간 사용 안내

수업에 필요한 도구를 모아, 나누고, 이어 쓰다. — 웨일 사이드바 · 웹

웹 버전: codersongpro.github.io/gorae/app/
앱 안 ❔ 버튼 → [따라 해보기]로 화면 안내를 볼 수 있어요

1시작하기

  • 웹: 주소로 바로 열려요. 설치가 필요 없어요. (폰·태블릿 가능)
  • 웨일 사이드바(웨일 PC): 소개 페이지의 [확장앱 ZIP 받기] → 압축 풀기 → 주소창에 whale://extensions → 아래쪽 개발자 모드 켜기 → 압축해제된 확장 프로그램 로드로 압축 푼 폴더 선택 → 오른쪽 사이드바의 고래 아이콘.
  • 웨일 클래스·팀보드·웨일온 화면 옆에서 바로 쓸 수 있어요.

2네 개의 곳간 (위쪽 탭)

인증 곳간파수꾼고래가 검수한 작품. 학생도 안심하고 사용
나눔 곳간모두가 올린 작품(검수 전). [미리 보기]로 먼저 열어 보기
내 곳간내 기기에만 저장. 만들기·수정·리믹스·★즐겨찾기
학급 꾸러미교사고래 전용. 작품을 묶어 학생에게 나눠 주기

3카드 읽는 법

  • 맑은 바다 검수 완료·학생 사용 가능 · 얕은 바다 미검수(교사가 먼저 확인) · 소용돌이 보류(실행 불가)
  • 초중고 쓰는 학교급. 세 개가 모두 있으면 공통 도구
  • 카드 색: 초록 수업자료 · 청록 학급운영 · 보라 행정업무
  • 제작자 줄: 🐋 검수된 작품 / 🫍 검수 전 작품 + 제작자 닉네임
  • 🐋 물뿜기(응원): 누르면 🐳로 바뀌고 숫자 +1, 10번 이상이면 🔥 인기
  • 📌 참고 전용: 학생은 보고 실행만 가능(담기·복사 불가)
  • 제목 앞 ▶를 누르면 설명·사용 방법이 펼쳐지고, 카드 오른쪽 ⋯에 리믹스·공유 등 나머지 동작이 있어요. 목록 끝에서 12개씩 이어져요.

4기본 사용 흐름

찾기›실행›내 곳간에 담기›리믹스·수정›공유
  • 찾기: 검색, 수업/업무·카테고리·학년·교과 필터, 정렬(새로 제작된 순·물뿜기 순)
  • 실행: 별도 창에서 격리 실행. 외부로 통신하지 않아요.
  • ＋ 추가 메뉴 → 만들기(HTML 붙여넣기·배포한 웹앱 주소) / 가져오기(꾸러미 파일·링크로 받은 작품)
  • 작품에 학생 이름·학교명·연락처를 넣지 마세요. 별명만 써요.

5교사고래 모드 들어가기

  1. 화면 위쪽의 🔒 자물쇠 아이콘을 눌러요.
  2. 교사고래 암호(PIN)를 입력하고 [확인]을 눌러요. (4~8자리 숫자)
  3. 위쪽에 보라색 띠 “교사고래 모드 켜짐”이 뜨면 성공! 아이콘이 🔓로 바뀌어요.
  4. 수업이 끝나면 🔓를 눌러 학생고래 모드로 돌아가요. 학생 앞에서는 학생고래 모드로 두세요.
  • 교사고래만 가능: 얕은 바다(미검수) 작품 보기·나눔 곳간 담기·검수 요청·학급 꾸러미·수업 진행·참고 전용 설정
  • 학생고래: 맑은 바다 작품만 보고 실행. 나눔 곳간은 미리 보기만
  • 암호를 잊었다면 암호 화면의 [암호를 잊었어요]로 초기화하고 새로 정해요.

6웨일 서비스와 연계하기

웨일 클래스① 교사고래 모드 → 학급 꾸러미 탭에서 작품 고르고 이름 적기 → [학급 꾸러미 만들기] ② [꾸러미 파일로 저장] + [과제 안내문 복사] ③ 클래스 글쓰기에 안내문을 붙여 넣고, 도구 모음 [파일]로 꾸러미 파일 첨부(글자 수 제한 때문에 파일로 첨부) ④ 학생은 파일을 받아 고래곳간 ＋ → 가져오기에서 열기
팀보드내 곳간에서 “꾸러미에 담기” 체크(또는 ★ 즐겨찾기) → [팀보드 카드 한 번에 복사]로 카드 글을 붙여 넣고, [팀보드 첨부용 파일 저장]한 파일은 팀보드 왼쪽 업로드(↑)로 올려요. 팀보드 화면에서는 사이드바 위에 안내 띠가 떠요.
웨일온수업 화면 옆 사이드바에 10분 이하 전체 활동 도구가 추천돼요. 학급 꾸러미의 [수업 진행으로 시작]을 누르면 도입 → 활동 → 정리 순서로 한 단계씩 열어요.
그 밖의 공유작품 카드 ⋯ 메뉴 → 웨일 스페이스에 공유에서 클래스용 안내·팀보드 전시용·일반 공유 글이나 바로 실행 링크를 복사해 붙여 넣어요.
같은 반 안에서의 공유는 꾸러미 파일이면 충분해요. 이름·학교명이 들어간 작품은 올리지 마세요.

7작품을 나누고 인증받기

내 곳간에서 ▶ 펼치기›인증 곳간에 보내기(교사고래) 또는 나눔 곳간에 공유›파수꾼고래 검수›맑은 바다로 인증
  • 나눔 곳간에서 🔥 인기 작품을 발견하면 교사고래 모드에서 [검수 요청]을 눌러 인증 곳간 후보로 올려요.
  • 다른 사람 작품을 바꿔 쓰려면 [리믹스](원작 이름이 함께 남아요). 참고 전용 자료는 그대로 쓰지 말고 출처를 적어요.
