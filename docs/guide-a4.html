앱 안 ❔ → [따라 해보기]로 화면 안내를 볼 수 있어요

1시작하기

  • 웹: 주소로 바로 열려요. 설치가 필요 없어요. (폰·태블릿 가능)
  • 웨일 사이드바(웨일 PC): 소개 페이지의 [확장앱 ZIP 받기] → 압축 풀기(extension 폴더가 생겨요) → 주소창에 whale://extensions → 아래의 개발자 모드 켜기 → 압축해제된 확장 프로그램을 로드합니다에서 extension 폴더 선택 → 오른쪽 사이드바의 고래 아이콘.

2화면 구성

공유 곳간위쪽 스위치로 인증 곳간(검수된 작품)과 나눔 곳간(모두가 올린 검수 전 작품, [미리 보기])을 오가요
내 곳간내 기기에만 저장. 만들기·수정·리믹스·★즐겨찾기. 작품을 체크하면 아래 선택 바(공유·꾸러미·수업 진행)
상단 아이콘＋ 만들기·가져오기 / 🔒 교사고래 모드 / ❔ 사용 방법 / 제목 누르면 첫 화면

3카드 읽는 법

초중고쓰는 학교급. 세 개(초 중 고)가 모두 있으면 어느 학교급에서나 쓰는 공통 도구 맑은 바다검수 서명 확인 · 학생도 사용 가능
HTML · 웹앱 · EXE작품 종류. HTML은 격리 실행, 웹앱은 새 창(외부 사이트), EXE는 직접 실행 프로그램이라 특히 조심 얕은 바다검수 전·점검에 걸림 → 교사가 먼저 확인
🐋 / 🫍 제작자🐋 검수된 작품, 🫍(범고래) 검수 전 작품 + 제작자 닉네임 소용돌이보류 → 실행할 수 없어요
🐋→🐳 물뿜기응원 버튼. 누르면 🐳로 바뀌고 +1 (앞 교사 · 뒤 학생). 10번 넘으면 🔥 인기 📌 참고 전용학생은 보고 실행만(담기·복사 불가). 그대로 쓰지 말고 출처를 적어요
카드 색초록 수업자료 · 청록 학급운영 · 보라 행정업무 (나눔 곳간은 주황 점선 막대) ★ · ✔ 담았어요★ 즐겨찾기(맨 위로) · ✔ 이미 내 곳간에 있음(누르면 이동)

4카드의 버튼

  • ▶ 제목: 설명·분류·사용 방법·프롬프트 레시피·점검 결과 펼치기
  • 실행: 별도 창에서 격리 실행. 외부 요청(fetch 등) 차단
  • 내 곳간에 담기 → 담은 뒤 ✔ 담았어요
  • ⋯: 리믹스·수정·삭제, 공유(클래스·팀보드·웨일온·실행 링크 복사)
  • 필터: 검색·초중고 칩·분류·정렬(새로 제작된 순/물뿜기 순), 학년·교과·시간·태그는 [필터]

5고래의 종류 · 교사고래 들어가기

  1. 🔒 자물쇠를 누르고 암호(PIN)를 입력 → [확인].
  2. 위쪽에 보라색 “교사고래 모드 켜짐” 띠가 뜨고 아이콘이 🔓로 바뀌면 성공. 수업 뒤 🔓를 눌러 학생고래로 돌려 두세요.
  • 학생고래(기본): 맑은 바다 보기·실행, 내 작품 만들기, 클래스·팀보드·웨일온 공유
  • 교사고래: + 얕은 바다 보기, 나눔 곳간 담기, 검수 요청, 수업 진행, 참고 전용 설정
  • 파수꾼고래: 검수 서명 담당 최고 관리자(검수 도구)

6웨일 클래스 · 팀보드 · 웨일온에 공유하기

카드 ⋯ → 공유(도구 하나) 또는 내 곳간에서 체크 → 아래 [공유·꾸러미](여러 개)를 누르면 ① 안내 글 복사 ② 작품 파일 저장 ③ 해당 서비스 새 탭 열기가 한 번에 돼요. 열린 화면에 붙여 넣고(Ctrl+V) 저장된 파일만 첨부하면 끝! 학생도 쓸 수 있어요.

웨일 클래스글쓰기에 붙여 넣고 도구 모음 [파일]로 첨부 → 학생은 파일을 받아 ＋ → 가져오기
팀보드전시 카드 글을 붙여 넣고 왼쪽 업로드(↑)로 파일 올리기 → 친구들 피드백
웨일온채팅·자료 공유에 붙여 넣고 파일 올리기. 사이드바에 10분 이하 전체 활동 도구 추천, 교사고래는 선택 바의 [수업 진행](도입 → 활동 → 정리)

7작품 올리기(업로드)와 인증받기

내 곳간에＋ → 만들기: HTML 붙여넣기 또는 .html 파일(1MB 이하) 올리기, 배포한 웹앱은 https 주소. 저장 전 자동 점검
나눔 곳간에내 곳간 카드 ▶ 펼치기 → 나눔 곳간에 공유하기: ① 파일 저장 ② 구글 폼 열기(닉네임·제목·설명 자동 입력) → 파일 업로드·제출. 웹앱은 주소만. 구글 이름·이메일이 기록되니 학생 개인정보는 넣지 마세요
인증 곳간에교사고래가 나눔 곳간 카드의 [검수 요청](🔥 인기작은 파랗게 강조) → 파수꾼고래가 검수
검수하기검수 도구 …/gorae/review.html → 비밀번호 입력 → [검수 목록] [살펴보기](점검·실행·코드) → [✔ 검수 완료] (GitHub 토큰을 한 번 저장해 두면 바로 올라가요)
