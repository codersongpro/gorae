# 네이버 폼 설정 안내 (큰 곳간 추천·고래 노래 접수)

고래곳간 사이드바(교사고래 모드)의 **큰 곳간에 보내기**는 접수 글을 복사하고 이 폼을 엽니다.
폼을 만든 뒤 주소(https)를 `extension/core/config.js`의 `formUrl`에 넣어 주세요.

## 폼 만들기
1. 네이버 폼에서 새 폼을 만듭니다. 제목 예: `고래곳간 큰 곳간 추천`
2. 설정에서 **로그인 없이 응답 허용**을 켭니다. (학생·다른 학교 교사도 낼 수 있게)
3. 응답자 정보(이름·이메일) 수집은 **끕니다**. 고래곳간은 개인정보를 받지 않습니다.
4. 안내문에 다음을 적습니다.
   - "고래곳간에서 복사된 내용을 아래 칸에 그대로 붙여 넣어 주세요."
   - "2주 안에 큰 곳간 목록에 없으면 반려된 것입니다. 반려 사유 유형은 큰 곳간 공지에 올립니다."

## 항목 (4개)
| 항목 | 종류 | 필수 |
| --- | --- | --- |
| 제출 종류 | 객관식: 작품 / 고래 노래 / 물뿜기 | 예 |
| 별명·학교급 | 단답형 (예: 푸른 고래 · 초등) | 예 |
| 붙여 넣기 | **장문형** (고래곳간에서 복사한 내용 전체) | 예 |
| 개인정보 미포함 확인 | 체크: "작품·후기 안에 학생 이름·사진·연락처가 없습니다" | 예 |

## 확인해야 할 것 (아직 모름)
- 장문형 칸에 몇 글자까지 들어가는지. 작품 꾸러미는 수천~수만 자일 수 있습니다.
  너무 길어 잘리면, 작품은 **꾸러미 파일**로 만들어 드라이브 링크로 받는 방식으로 바꿉니다.
- 파일 첨부 항목을 로그인 없이 쓸 수 있는지.

## 받은 뒤 (혹등고래 파수꾼)
1. 폼 응답에서 **붙여 넣기** 칸의 내용을 복사합니다.
2. 검수 도구 `https://codersongpro.github.io/gorae/review.html` → **2. 검수대**에 붙여 넣고 [확인하기]
3. 자동 점검 결과를 보고, 코드 보기·격리 실행으로 직접 확인합니다.
4. 배지·고래 픽·고래 노래를 고르고 [검수 서명 찍기] → [catalog.json에 넣기] → 내려받기
5. 내려받은 `catalog.json`으로 저장소의 `site/catalog.json`을 바꿔 올리면, 자동 배포 후 모두의 큰 곳간에 보입니다.

고래 노래 응답은 해당 작품(작품 id)을 검수대에서 다시 불러와, 고래 노래 칸에 `작성자 별명·학교급 | 후기`로 넣고 다시 서명합니다.

## 물뿜기 (서버 없음)
- 학생·교사가 💨을 누르면 기기에만 기록됩니다. [물뿜기 보내기]를 누르면 `[고래곳간 물뿜기]` 보고가 복사되고 이 폼이 열립니다. 제출 종류는 **물뿜기**를 고르게 안내하세요.
- 보고에는 작품 id와 교사/학생 구분만 들어 있습니다. 이름·기기 정보는 없습니다.
- 파수꾼·대왕고래는 검수 도구 **4. 물뿜기 집계**에 응답들을 한꺼번에 붙여 넣고 [집계하기] → catalog.json을 내려받아 `site/catalog.json`에 올립니다.
- 같은 보고 번호는 두 번 더하지 않습니다. 다만 익명이라 부풀릴 수 있으므로, 전시·정렬 기본값은 검수 서명이 있는 고래 픽입니다.
