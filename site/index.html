고래곳간

사람과 수업은 웨일이 연결하고, 고래곳간은 교육 자료와 도구를 이어 줍니다.

교사와 학생이 만든 수업 자료와 도구를 찾아 쓰고, 웨일 클래스·팀보드·웨일온으로 나눠요.

🐋 웨일 사이드바로도 쓸 수 있어요

  • 웨일 클래스 · 과제·공지로 배포
  • 팀보드 · 작품 카드 붙이기
  • 웨일온 · 수업 중 도구 추천

설치 방법 (웨일 PC 브라우저)

  1. 확장앱 ZIP을 받아 압축을 풀어요. 확장앱 ZIP 받기
  2. 웨일 주소창에 whale://extensions를 입력해요.
  3. 아래의 개발자 모드를 켜요.
  4. 압축해제된 확장 프로그램을 로드합니다로 extension 폴더를 골라요.
  5. 사이드바의 고래 아이콘을 누르면 끝!

▶ 화면 안내로 따라 하며 설치하기

웨일 스토어 등록 전 임시 설치 방법이에요.

설치 없이 웹으로 열기 검수 도구 (파수꾼고래)

어떻게 쓰나요?

  • 웹: 설치 없이 폰·태블릿에서도 열려요.
  • 웨일 사이드바: 웨일 PC에 설치하면 클래스·팀보드 옆에서 바로 써요.
  • 작품 링크: 받은 링크를 누르면 격리된 창에서 바로 실행돼요.
카드 읽는 법: 배지와 표시
초 · 중 · 고
쓰이는 학교급이에요. 셋 다 있으면 공통 도구예요.
맑은 바다 · 얕은 바다 · 소용돌이
맑은 바다: 검수 완료 · 얕은 바다: 검수 전, 교사 확인 · 소용돌이: 보류
제작자 · 🐬 / 🫍
🐬는 검수 완료, 🫍는 검수 전 작품이에요.
🐋 → 🐳 물뿜기 · 🔥 인기
응원 버튼이에요. 10번 이상 받으면 🔥 인기가 붙어요.
📌 참고 전용
학생은 보고 실행만 할 수 있어요.
카드 색
초록은 수업자료, 청록은 학급운영, 보라는 행정업무예요.
고래 종류: 학생고래 · 교사고래 · 파수꾼고래
🐋 학생고래
기본 모드예요. 검수된 작품을 쓰고, 만들고, 공유해요.
🔓 교사고래
🔒에 암호를 넣으면 켜져요. 검수 전 작품 담기, 검수 요청, 수업 진행을 해요.
🛡️ 파수꾼고래
작품을 검수하고 서명하는 관리자예요.
나누는 방법: 클래스 · 팀보드 · 웨일온
한 번에 세 가지
카드의 ⋯ → 공유, 여러 개는 내 곳간에서 체크 후 [공유·꾸러미]. 안내 글 복사·파일 저장·서비스 열기가 한 번에 돼요.
웨일 클래스 · 팀보드 · 웨일온
붙여 넣고 파일만 첨부하면 끝이에요.
바로 실행 링크
⋯ → 링크 복사. 받은 사람은 누르면 바로 실행돼요.
나눔 곳간·인증 곳간에 올리기
구글 폼으로 나눔 곳간에 올리고, [검수 요청]으로 인증 곳간에 보내요.
가져오는 방법
공유 곳간에서 담기
[내 곳간에 담기]를 눌러요. 나눔 곳간은 미리 보고 담아요.
파일·링크로 가져오기
＋ → 가져오기에 꾸러미 파일이나 링크를 넣어요.
내 작품 만들기
＋ → 만들기에서 HTML이나 웹앱 주소를 넣어요.
고쳐 쓰기
⋯ → 리믹스로 고쳐 새 작품을 만들어요.

로그인이 없고, 작품은 내 기기에만 저장돼요. 이름·이메일은 모으지 않아요.
